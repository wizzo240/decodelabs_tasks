DecodeLabs Internship - Project 1: Data Cleaning & Preparation
📊 Project Overview
This repository contains the first project for my Data Analytics Internship at DecodeLabs. The objective was to take a raw dataset, identify data quality issues, and perform a comprehensive data cleaning process to ensure reliable insights.

🛠️ Tools Used
Microsoft Excel: Used for data inspection, filtering, finding null values, and formatting.
🔍 Key Steps & Actions Taken
Handling Missing Values: Identified and resolved 309 missing values in the coupon code column, filling blanks with "No Coupon Code" to preserve context.
Standardization: Ensured consistent naming conventions across categorical columns (Order ID, Customer ID, Product, Shipping Address, Payment Method, Order Status, Tracking Number, and Referral Source).
Data Formatting: Cleaned Unit Price and Total Price columns to a uniform decimal format.
Quality Assurance Checks:
✔️ Verified 0 duplicate rows exist.
✔️ Confirmed correct data types across all columns.
✔️ Successfully resolved all missing data points.
