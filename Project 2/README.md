# Project 2: Exploratory Data Analysis (EDA)

## Goal
Analyze the e-commerce dataset (1,200 orders) to understand patterns, trends, and distributions.

## What Was Done
- Calculated descriptive statistics (mean, median, count, min, max) for order value, unit price, and items in cart
- Built PivotTables to analyze trends across:
  - Product category
  - Order status
  - Payment method
  - Referral source
  - Monthly sales
- Performed outlier detection using z-scores (flagging orders beyond ±2 standard deviations from the mean)
- Summarized key observations in a written report
